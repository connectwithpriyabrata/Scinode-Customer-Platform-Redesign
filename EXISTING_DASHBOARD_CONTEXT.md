## 1. Current Dashboard Sections

The dashboard is a **single-page, 4-state prototype**. A pill switcher in the top nav (`switchDay(0|1|10|30)`) toggles visibility of four sibling containers (`#day0`, `#day1`, `#day10`, `#day30`). A **shared top region** (greeting + hero card) renders above all states. Default state on load is **Day 10** (`switchDay(10)` runs at the end of the main script).

### Shared (all states)
- **Top nav** (`.top-nav`) — greeting ("Hello, Priya."), centered day toggle, notifications bell with dot, **Create Request** button (opens modal).
- **Sidebar** (`.sidebar`) — inline SVG Scinode logo, collapse toggle, nav groups: **Workspace** (Dashboard, Manufacturing, R&D, Products), **Intelligence** (Ask Scira), **Operations** (Requests + count badge), footer (Profile, Logout).
- **Hero card** (`.hero-card`) — dark navy 2-column banner: left = pill + headline + Scira pill-search; right = auto-rotating showcase carousel (3 slides: Project Delivery / Market Update / R&D Milestone).

### Day 0 — Onboarding ("getting started")
Empty-state activity cards (Start first request, Popular starting points, AI can help with, Explore with Scira) · **"What you can build with Scinode"** use-case carousel (7 photo cards) · **How We Execute Complex Chemistry** (React ecosystem section) · **Built for Regulated Chemistry** certifications scroller (GMP, FDA, ISO, EMA, ICH, WHO).

### Day 1 — Early usage
2×2 Conversion Matrix + recent activity (split 60/40 layout) · first requests table · suggested next steps · collapsed ecosystem/execution sections.

### Day 10 — Active usage (default)
5-card Conversion Matrix (47 requests) · Your recent Activity · **Action Required** · Active Projects (3 cards + overflow table) · Labs / Manufacturers / Products horizontal scrollers · **Scira Intelligence** insight cards · collapsed ecosystem section.

### Day 30 — Power user ("the operator")
Expanded Conversion Matrix incl. **Total Spend KPI ($1.21M)** · Spend Breakdown bar chart + Action Required (320px/1fr split) · 8 Active Projects (cards + table with spend column) · **Manufacturer Performance** scorecards (SynLab, ChemWorks, ReactChem — response time, on-time %, star quality, quotes accepted) · Recent Requests with tab filters + step-dot progress · deeper Scira Intelligence (3-up) · **Your Network** scroller + **Upcoming Milestones** timeline.

### Global
- **Create Request modal** (`#create-request-modal`) — 6-card grid: R&D Project, Manufacturing (CMO), CDMO, Quote, Sample, Expert Guidance.

## 3. Existing UX Patterns

- **Progressive disclosure across time** — the Day 0→1→10→30 axis is the core narrative: the same user's dashboard maturing as engagement deepens (empty states → active pipeline → operator analytics).
- **Section template** — almost every block is `section > .sec-hdr ( .sec-title + .sec-sub [+ .sec-link "View all →"] ) > grid/scroll body`. Consistent and repeatable.
- **Scira-first exploration** — search/CTA entry points route to Scira ("Ask Scira", hero pill-search, "Explore with Scira"). Aligns with product philosophy: Scira is the primary interaction layer.
- **Pipeline funnel** — Conversion Matrix is the recurring spine: Submitted → In Conversation → Quote → Converted → Active, with per-stage breakdown rows + a trend chip.
- **Status via step-dots** — request progress shown as `.step-row` of `.dot` (`.done` teal / `.now` gold / pending grey) + label.
- **Horizontal scrollers** — carousels for use cases, labs, manufacturers, products, certifications, network; arrows call `hscroll(id, dir)` / `ecoScroll()`; scrollbars hidden via `.scroll-area`.
- **Action urgency** — `.action-card.urgent` (red left border) + deadline badges (`badge-destructive` / `badge-warning`).
- **Collapsible heavy sections** — ecosystem/execution lists wrapped in shadcn-style collapsible/accordion with `aria-expanded` + `data-state`.
- **Hover affordances** — cards lift (`translateY(-1px)`) and reveal borders on hover; use-case cards reveal a "Start request" CTA on hover only.

## 4. Reusable Components (the design-system layer)

## 5. Layout Principles

- **App shell**: fixed sidebar (220px, collapses to 56px via `--sidebar-col`) + fixed top nav (56px, `--topnav`) + scrollable `.main` offset by both. Transitions are 0.2s ease.
- **Content rhythm**: `.content` = `padding:20px 28px; display:flex; flex-direction:column; gap:20px`. Sections are vertically stacked with consistent 20px gaps.
- **Grid conventions**: KPI grids `repeat(4,1fr)` / `repeat(5,1fr)` (`.kpi-grid-5`); activity `repeat(4,1fr)`; actions & projects `repeat(3,1fr)`; intel `repeat(2,1fr)` (3-up on Day 30); two-column splits via `.two-col` or inline `grid-template-columns`. Gaps mostly **12px** within a grid, **16–20px** between sections.
- **Cards**: white surface, `border-radius:10px`, 1px transparent border that appears on hover, padding ~16px 18–20px.
- **Hero**: 2-col `1fr 420px`, dark `#021825`, 16px radius, decorative radial glow + circle pseudo-elements.
- **Scrollers**: flex row, `gap:10–12px`, fixed-width children with `flex-shrink:0`, hidden scrollbar.

## 6. Design Conventions

**Typography**
- `--font: 'Outfit'` (body) · `--font-heading: 'Poppins'` (section headers). ⚠️ **`--font` / `--font-heading` are declared in TWO `:root` blocks** (≈line 16 and ≈line 950 in the ecosystem `<style id="eco-styles">`) — keep both in sync.
- Poppins is scoped to: `.sec-title, .sec-eyebrow, .modal-title, .nav-greeting-name, .intel-title, .act-va-title, .perf-name, .spend-total-num, .hero-card h1/h2, .hero-headline, .pc-top, .tbl th`. **Card titles and KPI labels intentionally use Outfit** (recent decision).
- Type scale (px): hero headline 32/600 · section title 15/600 · card title 13–14/500 · KPI value 26/500 · body 11–13 · eyebrow/labels 9–11 uppercase w/ letter-spacing. Numerics use `font-variant-numeric:tabular-nums`.

**Color** (primary `:root`, line ~10)
- Teal scale `--teal-50…700` (primary `--teal-500:#02968A`), Navy `--navy-50/500/700` (`#043E54`), accents `--sage #96DDA5`, `--gold #E5D62E` (the "now" step / action accent), `--indigo #6366F1`.
- Text ramp `--text-1 #1E293B / -2 #64748B / -3 #94A3B8`; borders `--border #E2E8F0 / -h #CBD5E1`; page bg `#F7F7F7`, surfaces white.
- ⚠️ The ecosystem `:root` (line ~911) **redefines** `--teal*` and `--teal-50/100` to slightly different hex values (`#018E7E` etc.) and adds `--ink*`, `--bg*`, `--r-*` radii, `--sh-*` shadows. Two token systems coexist; the ecosystem block scopes mostly to `.eco-*` and React components.
- Badge color pairs are fixed per type (see §4).

**Iconography**: inline SVGs, 24×24 viewBox, `stroke-width` 1.5–2.5, `currentColor`, Lucide/Feather style. No icon font.

**Voice (product philosophy — enforced)**: "Start Request", "Discuss Requirement", "Get Expert Guidance", "Continue Request". **Never** "Find Partners / View Suppliers / Vendor Network / Matchmaking." Suppliers stay invisible; the dashboard is an **execution / engagement / guidance** surface, not a marketplace or listing portal. Recommendations may cover products, technologies, market intelligence — **not** suppliers.

## 7. Implementation Constraints

- **Single static file, no build step.** All HTML, CSS, and JS live in `scinode-day10.html`. Served at `localhost:8899` via `python3 -m http.server 8899` from `/Users/priyabratadevi`. No bundler, no package.json, no transpile pipeline.
- **React via CDN only** — `react@18.3.1`, `react-dom@18.3.1`, `@babel/standalone@7.29.0` from unpkg, with in-browser Babel (`development.js` builds). Requires network access; JSX is transpiled at runtime (perf cost). React is confined to the Ecosystem section; **do not** assume a React app elsewhere.
- **Vanilla JS for everything else** — global functions: `switchDay`, `toggleSidebar`, `openModal/closeModal`, `hscroll`, `ecoScroll`, `toggleAccordion`, `toggleCollapsible`, `switchTab`, `goToSlide`. State lives in the DOM (classes + `aria-*` + `data-state`), not in a store.
- **Accessibility baked in** — `role`/`aria-*` on tabs, progressbars, dialogs, regions; `:focus-visible` rings; `.sr-only` headings per state. Preserve these when editing.
- **Day-state isolation** — content must live inside the correct `#day{n}` container or it leaks across states. Ecosystem mounts to per-day `#eco-day{n}` ids.
- **Two duplicated token blocks** — any global color/font change likely needs editing both `:root` blocks.
- **Hard-coded demo data** — all numbers, names (SynLab/ChemWorks/ReactChem, projects, REQ ids) are static literals; no data layer.
- **Not in version control at the served path** — the live file is `/Users/priyabratadevi/scinode-day10.html`; a git copy exists separately at `/Users/priyabratadevi/scinode-dashboard/`. These can drift; confirm which file is the edit target before changes.
- **Browser target**: modern evergreen (CSS grid, custom props, `:focus-visible`, `backdrop` modal). No IE/legacy concern.
